## Overview

**Live Site:** [https://hs14235.github.io/](https://hs14235.github.io/)

## Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (ES5+)
- **Framework:** Bootstrap 3.3.7
- **Libraries:** 
  - jQuery 3.x
  - WOW.js (scroll animations)
  - Magnific Popup (lightbox)
  - Owl Carousel (sliders)
  - Parallax.js (parallax effects)
- **Fonts:** Google Fonts (Poppins, Roboto Mono, Lora)
- **Icons:** Font Awesome, Ionicons, Linea Icons
- **Form Handling:** Formspree
- **Hosting:** GitHub Pages

## Features

-  Responsive design (mobile, tablet, desktop)
-  Smooth scroll navigation
-  Parallax effects on desktop
-  Animated sections with WOW.js
-  Contact form with spam protection
-  SEO optimized with structured data (JSON-LD)
-  Performance optimized (resource hints, lazy loading)
-  Accessibility features (ARIA labels, semantic HTML)

## Development

### Prerequisites

No build tools required! This is a static website that can be served directly.

### Local Development

1. Clone the repository:
```bash
git clone https://github.com/hs14235/hs14235.github.io.git
cd hs14235.github.io
```

2. Serve locally using any static server:
```bash
# Using Python 3
python -m http.server 8000

# Using Node.js http-server
npx http-server

# Using PHP
php -S localhost:8000
```

3. Open `http://localhost:8000` in your browser

### Making Changes

1. Edit `index.html` for content changes
2. Edit `css/tooplate-style.css` for styling
3. Edit `js/custom.js` for behavior changes
4. Test locally before committing
5. Push to GitHub - changes go live automatically via GitHub Pages

## Customization

To customize this portfolio for your own use:

1. Update personal information in `index.html`
2. Replace resume files in `images/` directory
3. Update project descriptions and links
4. Modify color scheme in `css/tooplate-style.css`
5. Update social media links
6. Change Formspree form endpoint in contact section
