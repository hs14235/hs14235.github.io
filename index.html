ML IBD Microbiome Pipeline

This project built a supervised machine learning pipeline to classify stool metagenomic samples as IBD or nonIBD using genus-level gut microbiome abundance data from the HMP2 / IBDMDB cohort. I merged public metadata with taxonomic profiles, collapsed Crohn’s disease and ulcerative colitis into a single IBD class, and used participant-aware splitting to prevent longitudinal leakage from repeated samples contributed by the same individuals. After comparing multiple models, Gradient Boosting delivered the best overall ranking performance, and threshold tuning improved the balance between catching true IBD cases and reducing false positives. The result is a research-oriented screening pipeline that shows microbial taxonomic abundance contains meaningful predictive signal for IBD status, while still requiring external validation before any clinical use.

Gulfstream Generative AI Capstone

Led an AI 3D Model Generation full-stack 3D asset pipeline built to reduce the manual work between a concept and a usable asset. A FastAPI backend manages asynchronous generation jobs across local TRELLIS text-to-3D and image-to-3D models, as well as cloud-based (ModelsLab & TripoSR) integration, with an optional OpenAI-powered prompt enhancement step for text inputs.
After generation, assets move through automated Blender normalization that centers the mesh in X/Y, amongst other parameters tailored by the clients' requirements in a browser-based Mesh Inspector built with React, TypeScript, and Three.js.
Designers can inspect geometry, dimensions, normalization metadata, and GLB/glTF material-readiness information before exporting the cleaned asset directly into Unreal Engine.

Features
• FastAPI backend for async generation orchestration
• TRELLIS, TripoSR, and ModelsLab for text-to-3D and image-to-3D workflows
• Optional OpenAI-powered prompt enhancement for text inputs
• Automated Blender normalization for grounding, transforms, pivot alignment, and Z-up orientation
• React, TypeScript, and Three.js Mesh Inspector for geometry and material-readiness review
• Unreal Engine export through Web Remote Control API and Python editor automation with compatibility safeguards
