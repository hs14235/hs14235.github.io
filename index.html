ML IBD Microbiome Pipeline

This project built a supervised machine learning pipeline to classify stool metagenomic samples as IBD or nonIBD using genus-level gut microbiome abundance data from the HMP2 / IBDMDB cohort. I merged public metadata with taxonomic profiles, collapsed Crohn’s disease and ulcerative colitis into a single IBD class, and used participant-aware splitting to prevent longitudinal leakage from repeated samples contributed by the same individuals. After comparing multiple models, Gradient Boosting delivered the best overall ranking performance, and threshold tuning improved the balance between catching true IBD cases and reducing false positives. The result is a research-oriented screening pipeline that shows microbial taxonomic abundance contains meaningful predictive signal for IBD status, while still requiring external validation before any clinical use.

Gulfstream Generative AI Capstone

Led a five-person team developing an AI-powered full-stack 3D asset-generation platform that reduced successful initial draft generation from multi-hour manual workflows to under 5 minutes. A FastAPI backend orchestrates asynchronous generation workflows across local TRELLIS and TripoSR models and cloud-based ModelsLab integration, with optional OpenAI-powered prompt enhancement for text inputs.
After generation, assets move through automated Blender normalization for centering, grounding, scale/orientation correction, and base-centered pivot handling before appearing in a browser-based Mesh Inspector built with React, TypeScript, and Three.js.
Designers can inspect geometry, dimensions, normalization metadata, and GLB/glTF material-readiness information before exporting cleaned assets into Unreal Engine through Remote Control API and Python editor automation.

Features
• FastAPI backend for async generation orchestration
• TRELLIS, TripoSR, and ModelsLab for text-to-3D and image-to-3D workflows
• Optional OpenAI-powered prompt enhancement for text inputs
• Automated Blender normalization for grounding, transforms, pivot alignment, and Z-up orientation
• React, TypeScript, and Three.js Mesh Inspector for geometry and material-readiness review
• Unreal Engine export through Web Remote Control API and Python editor automation with compatibility safeguards

meeting-to-tasks

meeting-to-tasks is a local-first meeting intelligence and developer-automation application that turns meeting transcripts into source-grounded, reviewable task drafts and optional GitHub issues.

A React + Vite frontend and MCP clients share the same FastAPI application services for retrieval, extraction, persistence, and GitHub operations. The system uses Sentence Transformers and FAISS for transcript retrieval, local Phi-3 Mini inference through Ollama, SQLite for durable application state, and explicit approval controls before GitHub writes.

Features
• React + Vite meeting workspace
• FastAPI REST endpoints
• Sentence Transformers + FAISS retrieval
• Local Ollama / Phi-3 Mini extraction
• SQLite persistence
• MCP tools over shared application services
• Source-grounded task drafts
• Approval-gated GitHub issue publication
